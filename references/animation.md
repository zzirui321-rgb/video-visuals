# 说明图与人物卡轻动画

用于解释机制、步骤、比较与关系的原创可编辑说明图，以及使用真实肖像的原创人物介绍卡。用户要求静态或指定别的动画时遵从用户；不把实拍证据、原帖截图或科学模拟重新拆成伪造过程。

## 先选择需要的运动

| 本次解释需求 | 制作方式 | 完成条件 |
|---|---|---|
| 用户要静态，或需要长时间读公式/原帖 | 完整静态版式 | PNG与实际使用的可编辑源文件 |
| 人物卡、节点关系、阶段步骤，主要依赖出现顺序 | 现有 SVG 分语义组＋FFmpeg 淡入 | 静音MP4、完整PNG、SVG与时序JSON；继续使用下述节奏和脚本 |
| 连续轨迹、随参数改变的曲线、连续形变或复杂同步比较 | 读取 [复杂动效规划](advanced-motion.md)，先判断分阶段静态是否足够；确需连续运动时记录需求与条件 | 当前只有经过实际渲染并查看的文件才能算动画成品；方案不计完成 |
| 真实实验或新闻视频 | 保留真实过程，选择相关源片区间 | 检查原始动作及字幕对应，不用遮罩或人为运动替代证据 |

所有方式沿用原字幕时间窗、项目风格和可编辑文字。字体实际加载后再测量文字框和溢出；采样检查初始、关键变化和完整终态。简单淡入无需新增运行时，复杂动效不触发自动安装、付费服务切换或口播时钟变更。

## 默认节奏

- 保留已确认的布局、文案和颜色，先按语义分组：一个框及其文字为一组，一个节点及其标签为一组。不要按屏幕竖条机械擦出，避免切字、半个节点和孤立箭头。
- 通常从左到右、从上到下或沿因果链出现；对比图可按行，网络图可按层。人物肖像、姓名和相关贡献作为一个语义组出现，避免观众先看到无身份头像或孤立简介。箭头在两端对象已出现时跟随淡入，回路最后出现。
- 背景稳定；标题、说明与出处在开始时显示或短暂淡入。每组淡入约0.25–0.45秒，组间间隔约0.45–0.75秒作为起点，依内容调整；不叠加弹跳、旋转、音效。
- 默认7秒窗口中，尽量在前3–4秒完成出现，最后至少2秒完整停留。以可读性和口播语义为准；不能为了动画擅自延长原片、挤占下一段或修改字幕时钟。

## 制作与交付

使用带命名分组的原生SVG或逐层SVG，加时序JSON；透明图层可用已有SVG渲染器渲染，再由已有FFmpeg合成静音MP4。此处是原生矢量版式的动画化，不授权重绘用户栅格素材。普通全屏交付默认1920×1080、30fps、H.264/yuv420p、无音轨；保留完整静态PNG和可编辑文字。读取 [项目偏好](account-preferences.md)，遵从当前项目约定与用户要求决定背景与布局。只有用户需要透明叠加时才交付兼容的透明格式及观看预览，不能把普通MP4描述为含透明通道。

可选复用脚本：

`node scripts/render_svg_reveal.cjs animation.json`

需要现成Node.js、sharp及FFmpeg；通过环境已有模块路径发现sharp，JSON中的ffmpeg填本机已验证路径，不自动安装。所有相对路径以JSON所在目录为基准。脚本拒绝覆盖已有MP4；使用版本化文件名。

```json
{
  "width": 1920, "height": 1080, "fps": 30, "duration": 7,
  "ffmpeg": "<已验证的FFmpeg路径>",
  "base_svg": "layers/base.svg",
  "layers": [
    {"name": "输入", "svg": "layers/input.svg", "start": 0.3, "fade": 0.35},
    {"name": "模型及连接", "svg": "layers/model.svg", "start": 1.0, "fade": 0.35}
  ],
  "render_dir": "render",
  "output": "00-01-23-000_Broll_机制_v2.mp4"
}
```

各图层画布尺寸相同；base含背景与常驻信息，其他层透明。helper只渲染并编码，不代替语义分组或视觉验收。交付便于预览的单段视频或合辑，并记录完整源文件与时序。

## 一轮检查

先核对组的覆盖完整且不重复、无切字。查看每段至少起始、中间和完整终态；重点核对箭头随关系出现、最后完整图未改变、文字未被压暗或叠影、片长与原时间窗一致、静音且能解码。必要时用若干时间采样帧核对淡入，不能只检查最终一帧。通过后再更新资产清单。
