# video-visuals · 视频配图

将主题、讲稿或 SRT 字幕变成视频封面、章节卡和带时间点的 B-roll。面向中文知识讲解、科普和口播视频，保留可编辑源文件、素材出处与交付清单。

## 能做什么

- 仅封面：同一设计独立适配 16:9 与 4:3，可按要求只做一个比例。
- 字幕配图：按原字幕时钟安排章节与 B-roll，优先真实科学图片、实验视频、人物资料和原帖。
- 说明动画：原创 SVG 按语义分组淡入，交付静音 MP4、静态 PNG 与时序 JSON。
- 校对与续做：按需校对 SRT，以资产清单继续缺失或未通过的内容。

它是一套给 AI 助手执行的工作流，不是独立视频编辑器，不自动完成最终剪辑，也不自动购买素材或发布视频。

## 安装

将此仓库完整克隆为技能目录，不能只复制 SKILL.md：

```sh
git clone https://github.com/zzirui321-rgb/video-visuals.git ~/.codex/skills/video-visuals
```

如果目录已经存在，先保留原技能和个人配置，选择另一个目录核对，不覆盖。其他支持 SKILL.md 的助手可将完整目录放入各自的技能目录；跨助手兼容性尚未实测。

## 使用示例

```text
使用 $video-visuals，基于这张课堂截图制作封面。
主题是“为什么光能推动粒子”，保留真实人物和黑板，输出 16:9 与 4:3。
```

```text
使用 $video-visuals，根据这个 SRT 制作章节卡、真实科学 B-roll 和必要的机制图。
保持字幕时钟，交付素材原文件、可编辑源文件、来源表与剪辑时间表。
```

项目风格放在项目自己的 `账号视觉约定.md` 中；公开版不包含作者的个人账号偏好。

## 工具与依赖

阅读技能与制作方案没有固定运行时要求。实际制作需要助手拥有相应的图像生成/编辑、浏览检索、下载、SVG 渲染和文件操作能力。当前工作流默认使用内置 image_gen；没有该工具时应说明缺项，替代付费服务由用户选择。

两个辅助脚本按需使用，不会自动安装依赖：

| 脚本 | 依赖 | 用途 |
|---|---|---|
| `scripts/check_assets.py` | Python 3.10+；检查 PNG 需 Pillow；检查视频需 ffprobe | 读 SRT、检查清单和媒体结构，不代替视觉审核 |
| `scripts/render_svg_reveal.cjs` | Node.js、sharp、FFmpeg（含 libx264） | 将原创分层 SVG 合成为静音淡入动画 |

脚本命令与清单规范见 [manifest](references/manifest.md) 和 [animation](references/animation.md)。生成、渲染和第三方素材服务可能有独立费用、条款和许可；本仓库许可证不授予这些素材的使用权。

## 维护与本地同步

`tools/export_public.py` 从个人安装目录导出固定文件清单，替换个人偏好入口，排除个人学习笔记；新增文件或仍含个人账号措辞/常见本地路径、凭据模式时停止并要求人工检查。它不删除文件，也不会自行提交或推送。

```sh
python tools/export_public.py --source <本地技能目录>
python tools/export_public.py --source <本地技能目录> --write
git diff
```

审核差异后再提交并推送。导出检查只能辅助发现问题，不是完整的敏感信息检测。维护者应同时检查 README、工具和许可证等仓库文件。

请通过 Issue 提供使用场景和脱敏复现材料；不要提交个人字幕、肖像、账户信息或未获授权的媒体。
